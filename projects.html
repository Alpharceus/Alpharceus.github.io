FPGA Monte Carlo — Lattice Transport & Galton Board

Done

Two VHDL Monte Carlo designs for the Nexys A7: a random walk on a 7×7 lattice and an LFSR-driven Galton board, each streaming a live histogram over UART.

Show Summary
The lattice design runs seven LFSR walkers with per-site reflection and transfer probabilities into absorbing detectors; the Galton board drops pseudo-random balls through seven stages into eight bins with an LED display. Both stream their results to a Python viewer over UART.

Project Hermes — Point-to-Point File Transfer

In progress

Point-to-point file transfer between one person's devices, staged through a token-gated Raspberry Pi relay or sent directly over pinned mutual TLS.

Show Summary
Files move from exactly one device to exactly one other, with a SHA-256 receipt at the end. The staged path streams uploads to a small Raspberry Pi service over Tailscale with hash-verified acks and 72h/24h retention; when both ends are awake, a mutual-TLS direct path pinned to each peer's certificate is used, alongside a PySide6 tray app. The staging service is built and unit-tested, with Pi deployment in progress.

Project Gabriel — Encrypted Group Chat for One

Done

A group chat for one person's devices and agents, end-to-end encrypted over Firestore with FCM push.

Show Summary
Messages are AES-256-GCM encrypted on the sending device and decrypted on the receiving one, and Firestore stores ciphertext only. Built as a Python library and CLI, receiver daemons with SQLite mirrors and a push relay, and an installable PWA client that needs no native builds.
