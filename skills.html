SKILLS — INTERFEROMETRIC INDEX

Light in. Skill out.

An 8-mode Mach–Zehnder mesh — the same tunable building block as the electrically tuned MZI meshes I work on. One laser enters the lattice. Pick a skill group and the mesh is reprogrammed so the light lands on that group’s outputs, or click a single output to send it all there.

8-mode rectangular (Clements) mesh · 28 MZIs · reprogrammed per channel. Each retune changes the seven splitter-tree MZIs and the output phases; hover an MZI for its settings.
